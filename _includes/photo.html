{%- comment -%} Renders a photo from the CDN with an optional EXIF credit line. Reads the `photo:` map out of the post's front matter (see CLAUDE.md, "Photos on the CDN"). Call it where you want the photo to sit in the post: {% include photo.html %} `exif: true` prints the camera line and the copyright; `exif: false` or omitting it prints the photo bare. The published JPEGs have no EXIF in them -- the prep script strips it -- so these values are written into front matter at publish time by `bin/photo-frontmatter`, not read from the file by Jekyll. Caption parts are assembled into a pipe-delimited string and split, because Liquid has no way to build an array in place. {%- endcomment -%} {%- assign p = include.photo | default: page.photo -%} {%- if p and p.src -%} {%- endif -%}
